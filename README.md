# Programa 1 — NotchBar (nombre provisional)

Utilidad de escritorio para **Windows 10/11**: una pastilla ("notch") minimalista en el borde superior de la pantalla que se expande al pasar el ratón. Hecha en **C# / .NET 10 / WPF**.

Combina ideas de **Nock** (el notch y los widgets del sistema) y **Kissa** (lo que suena, carátula y letras sincronizadas), con un estilo propio: **minimalista, blanco o negro, con tema cambiable**.

> Estado: **solo planeado**. No hay código todavía. Primer día de trabajo: seguir `docs/03-ROADMAP.md` desde el hito M0.
